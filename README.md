# Brew & Bloom Café

A responsive café website built with HTML, CSS and vanilla JavaScript.

## Features
- Premium cream and coffee-brown design
- Responsive desktop, tablet and mobile layouts
- Menu categories and live search
- Shopping cart with quantity controls, remove buttons and automatic totals
- Demo checkout (no real payment processing)
- Mobile navigation menu
- Accessible labels and reduced-motion support

## Run locally
1. Download the folder.
2. Open the `brew-and-bloom-cafe` folder in Visual Studio Code.
3. Open `index.html` in your browser, or install the **Live Server** extension in VS Code.
4. If using Live Server, right-click `index.html` and choose **Open with Live Server**.

Internet is needed for Google Fonts and the Unsplash menu photos. The website itself does not require a backend.
